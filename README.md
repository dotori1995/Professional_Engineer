# 정보관리기술사 단어장

2027년 1회 정보관리기술사 시험을 준비하며 만든 **토픽 단어장**입니다.
13개 도메인, 2,042개 토픽의 정의·필수 키워드·두음·목차를 휴대폰 한 화면에서 보고 외울 수 있게 정리했습니다.

**👉 https://dotori1995.github.io/Professional_Engineer/**

## 사용법

| 화면 | 하는 일 |
| --- | --- |
| **목록** | 도메인별 토픽 목록. 제목·키워드·정의를 한 번에 검색 |
| **토픽** | 정의 → 필수·참고 키워드 → 두음 → 목차, 아래 '자세히'에서 항목별 설명 |
| **카드** | 앞면 토픽명, 탭하면 뒷면(정의·키워드·두음·목차). 스와이프로 넘기기 |
| **서술** | 토픽명만 보고 떠오르는 키워드를 적은 뒤 필수 키워드와 비교해 체크 |

- **★ 중요 토픽**: 학습 자료의 중요도 표시를 기준으로 고른 토픽에 ★ 표시. 목록·카드·서술에서 **중요만**을 켜면 ★ 토픽만 봅니다.
- **섞기**: 카드·서술 순서를 무작위로.
- **도메인 변경**: 왼쪽 위 ☰ 메뉴 → 도메인 → 토픽.
- **약어**: 화면의 영문 약어는 그 토픽 문맥에 맞는 풀네임으로 함께 표시됩니다.
- **모바일**: 한 화면에 맞춰 보이도록 만들었습니다. 홈 화면에 추가하면 앱처럼 열리고, 한 번 연 뒤에는 오프라인에서도 동작합니다.
  - iPhone(Safari): 공유 → 홈 화면에 추가
  - Android(Chrome): ⋮ → 홈 화면에 추가
- 🌓 버튼으로 다크 모드 전환.

## 내용은 이렇게 만들었습니다

- 토픽 목록과 범위는 기술사 학습 교재를 기준으로 하고, 교재에 없는 토픽은 넣지 않았습니다.
- 정의·키워드·목차는 답안에 바로 쓸 수 있는 용어 중심으로 직접 다시 썼습니다. 용어는 `한글(English)`로 병기합니다.
- 표준 번호·연도·개수 같은 사실은 표준 문서와 공식 자료로 확인하고, 교재 이후 바뀐 내용(개정 표준, 신규 법령 등)은 최신 기준으로 고쳤습니다.
- 두음은 교재에 있는 것만 싣고, 각 글자가 무엇을 뜻하는지 풀이를 붙였습니다.
- 틀린 내용을 발견하면 Issues로 알려 주세요.
